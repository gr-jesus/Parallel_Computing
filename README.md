# Financial Time Series Predictor & Parallel Grid Search

This repository contains a Python-based machine learning pipeline designed to forecast financial asset prices. It automates the process of fetching historical stock data, preprocessing it into time-series sequences, and finding the best predictive model using a custom, fully parallelized hyperparameter grid search.

## Features

* **Automated Data Ingestion:** Fetches historical stock prices directly from Yahoo Finance using `yfinance`.

* **Robust Preprocessing:**

  * Computes log returns to stabilize the variance of the financial time series.

  * Scales data using `StandardScaler` (strictly fitted on training data to prevent data leakage).

  * Converts 1D arrays into 2D time-window sequences (X, y) for supervised learning.

  * Splits data sequentially into Training, Validation, and Test sets to respect chronological order.

* **Parallel Hyperparameter Tuning:** Utilizes Python's `multiprocessing` library to train and evaluate multiple model configurations concurrently across available CPU cores, drastically reducing training time.

* **Model Agnostic:** Easily configurable to test different scikit-learn compatible regression models (e.g., SVR, LightGBM, ElasticNet).

* **Comprehensive Evaluation:** Evaluates the best model on the unseen Test set using $R^2$, Mean Squared Error (MSE), and Mean Absolute Error (MAE).

## Project Structure

* `data_pipeline.py`: Handles data downloading, transformation, scaling, sequence generation, and dataset splitting.

* `grid_search.py`: Implements the parallel grid search, defines the hyperparameter space, trains the models, and reports the final metrics.

* `requirements.txt`: Contains all the necessary Python dependencies to run the project.

## Installation

1. **Clone the repository:**

   ```
   git clone https://github.com/gr-jesus/Parallel_Computing.git
   cd Parallel_Computing
   
   ```

2. **Create a virtual environment (Recommended):**

   ```
   python -m venv venv
   source venv/bin/activate  # On Windows use `venv\Scripts\activate`
   
   ```

3. **Install the dependencies:**

   ```
   pip install -r requirements.txt
   
   ```

## Usage

To run the full pipeline, including data fetching, preprocessing, and the parallel grid search, simply execute the `grid_search.py` script:

```
python grid_search.py

```

By default, the script is configured to fetch data for NVIDIA (`NVDA`) and optimize a Support Vector Regressor (`SVR`). You can easily modify the `main()` function in `grid_search.py` to change the ticker, the model, or the hyperparameter space.

You can also run the data pipeline independently to verify data fetching and splitting:

```
python data_pipeline.py

```
